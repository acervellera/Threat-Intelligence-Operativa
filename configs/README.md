# Configurazioni

Qui verranno pubblicate solo configurazioni didattiche validate e prive di segreti.

Struttura prevista:

```text
configs/
├── sysmon/
├── wazuh/windows-eventchannel/
├── wazuh/rules/
├── auditd/
└── fim/
```

Ogni configurazione deve includere versione testata, hash, data UTC, scopo, limiti, rollback e collegamento al test che la valida.
